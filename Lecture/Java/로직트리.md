
# 🌳 로직 트리(Logic Tree)란?

- **하나의 문제 또는 아이디어를 계층적으로 구조화**해서 하위 항목으로 점점 분해해 나가는 도식적 사고 도구

- **복잡한 주제를 작게 쪼개**고, 그 관계를 **트리(tree)처럼 시각화**하는 방식

```
[순자산] 80,000
├─ [자산] 280,000
│  ├─ 당좌자산: 50,000
│  ├─ 재고자산: 30,000
│  ├─ 투자자산: 70,000
│  ├─ 유형자산: 100,000
│  └─ 무형자산: 30,000
└─ [부채] 200,000
   ├─ 유동부채: 150,000
   └─ 비유동부채: 50,000
```
